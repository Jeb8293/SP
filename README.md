# Selfless Progression
GitHub Pages-ready multi-page concept site.

Pages:
- index.html
- shop.html
- product.html
- about.html
- contact.html

Upload all files to the repository root. Then enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).

Replace placeholder products, contact details, and form functionality before a real launch.


## iPhone-friendly upload
All site files, including the logo, live at the repository root. No folders need to be created in GitHub.
